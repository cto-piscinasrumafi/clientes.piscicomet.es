# Clientes Piscicomet

Web independiente para profesionales y empresas del sector de piscinas, prevista para publicarse en https://clientes.piscicomet.es.

## Desarrollo local

Requisitos: Node.js 20.9 o posterior.

1. Instala dependencias con npm install.
2. Arranca el servidor con npm run dev.
3. Abre http://localhost:3000.

## Rutas

- /: landing informativa para empresas colaboradoras.
- /login: pantalla de acceso preparada visualmente; la autenticación se implementará en una fase posterior.

## Estado

La landing, la navegación básica y la estructura visual de login están preparadas. El formulario de acceso, la gestión de cuentas, el backend y la configuración final de dominio/despliegue quedan pendientes. No hay credenciales ni datos de producción en este repositorio.

La web usa Next.js App Router. Los estilos globales se encuentran en app/globals.css.
